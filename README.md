# RealEstate Demo — Website + CRM

This ZIP contains the entire React/Vite property website and an expanded real-estate CRM.

**START HERE:** [README-CRM-SETUP.md](README-CRM-SETUP.md) contains the required Supabase migration, admin bootstrap, employee login setup, feature scope and validation limitations. [QA-TEST-CHECKLIST.md](QA-TEST-CHECKLIST.md) lists critical tests before a client launch.

Commands after configuring the project: `npm ci`, `npm run dev`, and `npm run build`. Do not expose secret service_role keys in Vite.

The source has passed syntax parsing but has **not** passed a full production build or live Supabase/browser validation in this environment.
